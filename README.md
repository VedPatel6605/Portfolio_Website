A modern, responsive portfolio website built with Next.js, TypeScript, and Tailwind CSS. This portfolio showcases my skills, projects, and experience in web development.

## 🚀 Features

- **Modern Design**: Clean and professional UI with subtle animations and effects
- **Responsive Layout**: Fully responsive design that works on all devices
- **Dark Theme**: Elegant dark theme with gradient accents
- **Interactive Elements**: Smooth animations and transitions
- **Performance Optimized**: Built with performance in mind using Next.js

## 🛠️ Tech Stack

- **Framework**: Next.js 14
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide Icons
- **Animations**: Framer Motion
- **Deployment**: Vercel

## 📋 Sections

1. **Hero Section**
   - Professional introduction
   - Status badge
   - Call-to-action buttons

2. **About Section**
   - Personal background
   - Professional summary
   - Key highlights

3. **Skills Section**
   - Technical skills
   - Tools and technologies
   - Skill categories

4. **Projects Section**
   - Featured projects
   - Project details
   - Live demos and GitHub links

5. **Contact Section**
   - Contact form
   - Social media links
   - Direct contact information

## 🎨 Design Elements

- **Color Scheme**: Dark theme with blue, purple, and cyan accents
- **Typography**: Modern sans-serif fonts
- **Animations**: Subtle hover effects and transitions
- **Background**: Dynamic gradient orbs and grid pattern
- **Components**: Glass-morphism effects and gradient text

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/portfolio.git
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🔧 Customization

1. **Content**: Update the content in respective section components
2. **Styling**: Modify Tailwind classes in components
3. **Colors**: Adjust color scheme in `tailwind.config.js`
4. **Images**: Replace images in the `public/images` directory

## 📱 Responsive Design

- Mobile-first approach

  - 2xl: 1536px
